# OIBSIP_python_task1
BMI Calculator using Python

## Objective
The objective of this project is to calculate the Body Mass Index (BMI) of a user based on their height and weight and classify it into health categories.

## Steps Performed
1. Took user input for weight (kg) and height (meters).
2. Applied the BMI formula: BMI = weight / (height * height).
3. Classified BMI into categories such as Underweight, Normal, and Overweight.
4. Displayed the BMI value and health status.

## Tools Used
- Python
- Visual Studio Code
- GitHub

## Outcome
The program successfully calculates BMI and provides an appropriate health classification in a simple and user-friendly manner.
